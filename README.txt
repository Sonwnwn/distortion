DISTORTION

Откройте index.html в браузере. Установка не нужна.
Сайт написан на HTML, CSS и JavaScript без библиотек.
Фотографии и шрифт находятся в assets и работают локально.

Есть адаптивная сетка, мобильное меню, фильтры каталога,
модальные окна, плавная прокрутка и проверка формы.
При настройке уменьшенного движения анимация отключается.

Форма демонстрационная. Она НЕ отправляет данные.
После проверки можно скачать текст обращения.
Для реальной отправки нужен сервер или сервис обработки форм.

Перед использованием добавьте реальные телефон, email,
соцсети, сведения о товарах и политику обработки данных.
Названия моделей условные; стоимость и материал не указаны.

Категории фотографий соответствуют порядку приложений в задании.
Основной шрифт PT Mono, как на сайте-референсе.
